How the calculation works
The table uses one physical coordinate system for the graphics and shot solver. Ball positions, pockets, cushion points and routes are calculated from the same table geometry.

Direct and cut shots use ghost-ball collision geometry. One-rail banks use reflected-pocket geometry against the cushion centerline. Combination shots calculate the first object-ball contact and then the resulting path toward the selected pocket.

Other balls can be placed on the table as obstructions or combination targets. The solver will not simply erase the route when a ball blocks the obvious line; it will search for another legal route when one exists.
