How the calculation works
The solver uses one physical coordinate system for the table, balls, cushions and shot paths. Balls have a 2.25-inch diameter and all routes account for ball-center geometry. Direct shots use ghost-ball collision geometry. Banks reflect the object-ball route from the cushion. Kicks reflect the cue-ball route before contact with the object ball. Other balls on the table are treated as collision constraints, so a route is rejected when another ball blocks the intended path. Combination routes are also evaluated when a second object ball is selected as the intermediate contact.

This is a geometric shot planner, not a physics simulator. Speed, spin, throw, cloth, cushion response, pocket shelf depth and table condition can change the real result.
